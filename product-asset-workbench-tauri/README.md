# PLM 产品资产工作台

Windows 桌面工具，通过本机安全桥接连接 PLM 悬浮助手，预览全部已定稿 SKU，并把交付资产写入对应产品目录。

## 使用流程

1. 安装并打开“PLM 产品资产工作台”。
2. 点击右上角“连接悬浮助手”，复制工作台显示的连接码。
3. 更新并打开 `outputs/plm-material-summary.user.js`，进入悬浮助手“设置 → 桌面工作台”，粘贴连接码并连接。
4. 在工作台选择本地产品根目录，点击“同步已定稿产品”。
5. 检查目录匹配和缺失提示；未匹配 SKU 可点击文件夹按钮手动指定目录。
6. 勾选产品，点击“批量生成所选资产”。

默认不会覆盖已有文件。需要重新生成时，先开启“覆盖已有文件”。

## 主图填表

打开“主图填表”，选择产品图片根目录，粘贴 Excel 编码列，再点击“按编码查找主图1”。递归查找编码产品文件夹下的 `主图1.jpg/jpeg/png/webp`（也支持 `主图01`），按粘贴顺序展示，保留重复编码、空行和 `/`。同编码有多张主图1时必须手动选择，缺图和无效编码保留原行并显示提示。

例如选择 `D:\工作\7月`，即可找到 `AMZ 尿素保湿足霜 SKU00046312\套图\AMZ 尿素足霜 SKU00046312\主图\主图1.jpg`。一次遍历所选目录下所有层级，无需逐个指定产品文件夹。

“导出带图片的 Excel”生成新文件：无表头，A 列为编码、B 列为嵌入并随单元格移动的图片、C 列为缺图提示。图片保持比例，不依赖原图路径，不覆盖已有文件。导出使用兼容 Excel 的单元格锚定图片，不是新版 Excel 的 IMAGE 函数或“置于单元格”数据类型。

## 手机远程

1. 在桌面工作台右上角打开连接设置。
2. 在“手机远程工作台”输入与云备份一致的姓名和备份密码并启用。
3. 手机访问 `https://velvet.qzz.io/remote/`，用同一姓名和备份密码登录；可在浏览器菜单中添加到主屏幕。
4. 保持电脑资产工作台打开。生成资产还需要 PLM 页面里的悬浮助手保持连接；扫描上传会使用“定稿资产”已配置的产品根目录。

手机只下达指令，不上传或中转图包。ZIP、XLSX、图片和产品文件夹始终从电脑本地查找。电脑暂时离线时，指令会在云端排队，重新打开工作台后自动领取。

## 输出结构

```text
产品目录\
└─ 套图\
   ├─ 英文参数图\
   │  └─ 英文参数图.jpg
   ├─ 产品参数图\
   │  └─ 尺寸.jpg
   └─ 品牌 产品名 SKU.xlsx
```

英文参数图和尺寸图优先使用产品目录根部的 `透明.png`。缺少透明图时只生成 Excel，并在队列中显示提醒。

## 开发命令

```powershell
npm.cmd install
npm.cmd run build
npm.cmd run tauri dev
npm.cmd run tauri build
```

Rust 核心测试：

```powershell
cd src-tauri
cargo test
```

Windows 安装包可通过 GitHub Actions 的 `Build Workbench Windows Installer` 手动构建。流程先运行前端与 Rust 测试，再生成 NSIS 安装包，成功后下载 `PLM-Product-Asset-Workbench-Windows` artifact 中的 `*-setup.exe`。

本机桥接只监听 `127.0.0.1:37191`，使用工作台生成的高熵连接码配对，不读取 PLM 密码、Cookie 或云备份密钥。
