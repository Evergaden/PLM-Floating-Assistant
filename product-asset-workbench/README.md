# Product Asset Workbench

面向 PLM 成品交付的桌面工作台：从 PLM 浮动助手的云备份读取已定稿产品，批量生成资料和图片资产，并保留图包 ZIP 的归档与规则化重命名功能。

## 它能做什么

- 同步 PLM 助手“今日工作台”里已定稿的 SKU、产品资料、尺寸、物料编码和商品图链接。
- 按勾选批量生成每个产品的：
  - `套图/品牌 产品名 SKU.xlsx`
  - `套图/产品名 SKU/英文参数图/英文参数图.jpg`
  - `套图/产品名 SKU/产品参数图/尺寸.jpg`
  - `套图/产品名 SKU/plm-asset-manifest.json`（生成来源和清单）
- 输出根目录已有同 SKU 产品文件夹时直接写入；没有时按 `{sku}_{brand}_{name}` 自动建立。
- 将带 SKU 的 ZIP 图包解压到对应产品的 `套图` 文件夹，并依据 `rules.txt` 命名主图、详情图等文件。

## 第一次连接 PLM

1. 在 PLM 浮动助手的“云备份”页，设置一个自己的备份密钥并点击“上传备份”。
2. 双击 `启动.bat`。首次会先显示安装窗口，安装 `PySide6`、`Pillow` 和 `openpyxl`，不会再无提示退出。
3. 在“定稿队列”粘贴同一个备份密钥，选择产品文件夹根目录，点击“同步已定稿产品”。
4. 勾选 SKU 和需要的资产，点击“批量生成所选资产”。

工作台直接读取 PLM 助手的标准云备份，不需要 PLM 登录密码、Cookie 或开放本机端口。Excel 直接使用 PLM 悬浮助手同源的 `excel-template.xlsx`，保留原有单元格、公式、商品图位置和文件名规则；英文参数图、尺寸图采用悬浮助手同一套 1600px 参数图排版与尺寸标线，并优先采用产品根目录的 `透明.png`。同步后会预览全部已定稿编码，自动标注缺少透明图、英文名称、净含量、毛重、成分、对标链接或尺寸的产品；勾选“手动”可将这些 SKU 排除出本次批量生成。

## 图包归档

切换到“图包归档”页，添加或直接拖入 ZIP，选择与产品文件夹相同的根目录后执行。ZIP 文件名必须带 SKU，例如 `主图_SKU00044974_001.zip`。`rules.txt` 的每行格式为：

```text
正则表达式|新名称
```

`config.json` 保存本机路径和云备份密钥，已被 Git 忽略；旧版 `config.txt` 会在首次启动时自动迁移路径与图包选项。
